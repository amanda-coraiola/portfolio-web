# 🌐 Personal Web Portfolio & Project Hub

[![Live Demo](https://img.shields.io/badge/Website-Live%20Demo-brightgreen?style=for-the-badge&logo=githubpages)](https://amanda-coraiola.github.io/portfolio-web/)

> Landing page e portfólio pessoal responsivo desenvolvido com HTML5, CSS3 e JavaScript puro, integrando e centralizando os principais projetos de Análise de Dados, Visão Computacional e Engenharia de Dados.

---

## 🎯 Sobre o Projeto

Este site foi projetado e desenvolvido para servir como a vitrine central das minhas entregas tecnológicas. A aplicação conta com um design moderno, totalmente responsivo, suporte dinâmico a temas e filtros interativos para que recrutadores e gestores explorem facilmente os meus projetos e competências em dados.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível da página.
* **CSS3:** Estilização moderna com CSS Variables (Custom Properties), Flexbox, CSS Grid e media queries para responsividade em dispositivos móveis e desktop.
* **JavaScript (Vanilla JS):** Manipulação dinâmica do DOM para:
  * Alternador de tema **Dark / Light Mode**.
  * Filtro interativo de projetos por categoria (*Analytics*, *Visão / IA* e *Engenharia*).
* **FontAwesome:** Ícones vetoriais integrados para interface do usuário.
* **GitHub Pages:** Hospedagem e deploy contínuo e público.

---

## ✨ Funcionalidades Principais

* **Hero Section & Apresentação:** Destaque profissional com links diretos para contatos e repositórios.
* **Seção de Competências:** Exibição visual das principais linguagens e ferramentas do ecossistema de dados.
* **Filtros Interativos de Projetos (JS):**
  * **Analytics:** *Trade Analytics Streamlit*
  * **Visão / IA:** *PDV Scan - Computer Vision*
  * **Engenharia:** *Retail ETL Pipeline*
* **Tema Dinâmico (Light / Dark Mode):** Permite ao usuário alternar a paleta de cores da interface com um único clique.
